## 📖 项目简介

**SR-4220** 是一款适配 **42步进电机** 的 **56速比** 低成本针齿全轴承 RV 减速器。本项目的初衷是为了学习和验证 RV 减速器的机械结构与运动学原理。

*   **适配电机**：42步进电机
*   **减速比**：56:1
*   **设计特点**：低成本、针齿全轴承设计

---

## ⚠️ 作者寄语与重要警告（必看）

其实我真的不建议复刻这个版本 T.T。
后面会有更好的设计。**除非你对 RV 实在是感兴趣，不然我建议只用来学习即可**。

因为是低价加工，精度不可能特别高，而众所周知 RV 减速器对精度要求特别高，所以这将会是一场**装配灾难**：三曲轴相对同心度、垂直度……唉唉，可惜我这优雅的设计竟败倒在了加工和装配误差面前。

不过用心点当然是可以装成功的！！毕竟我已经做了好几个了。如果你决定要复刻，请务必仔细阅读下方的复刻建议。

## 🛠️ 复刻建议与避坑指南

### 一、 加工与采购指南
1. **铝CNC件**：可以直接另存为STEP，然后上传 **铨洲智能制造** 加工。摆线盘和偏心套选择**精加工**，其他不选精加工。
2. **轴承采购**：轴承量很大，可以直接上 **1688** 找那种专门做轴承的。693ZZ这样的轴承钢轴承只要五毛钱一个，如果选碳钢好像只要一毛钱一个。
3. **齿轮标准件**：都是可以直接上淘宝买到的，一般五六块钱一个。中间太阳轮齿轮选 **K型**，行星轮选 **A型**，行星轮可以备注一下要 **松配合** 的。
4. **分体曲轴D型轴**：这个D型轴其实有点贵，好像要四块钱一根。
5. **PLA垫片**：设计里涉及到的PLA垫片，可以直接换成相应内径的 **金属垫片**（偷懒没有在图里面改了）。
6. **手工铰刀**：可以买个 **D3的手工铰刀** 备用，防止加工误差导致销轴插不进去。

### 二、 装配与点胶注意事项
7. **点胶规范**：看装配过程中，要点轴承胶的记得点胶，用 **乐泰638** 就行。**记得千万不能弄多了，不然渗入轴承就不好搞了！** 还有一定要小心点，因为沾上了之后就很难拆下来了。
8. **点胶位置**：主要是 **分体曲轴部分** 还有 **曲轴和摆线盘配合处**，相当于轴向约束。
9. **针齿轴承装配**：针齿轴承部分有可能因为轴承公差问题很难穿进去，所以很建议你有个 **压台** 方便装配。
10. **垂直度控制**：摆盘和曲轴点胶的时候千万要小心，**要保证垂直度**，不然会上下偏振的。
11. **太阳轮顶丝**：拧的时候记得小心些，不然有可能滑丝就拆不下来了。

### 三、 调试与磨合
12. **反驱测试**：带电机装配好后试试可不可以反驱。如果根本反驱不了说明装配有问题（垂直度会影响齿轮啮合）。
13. **干磨磨合**：不用太担心反驱问题，**不要加润滑脂**，直接上电 **干磨**，运行个一个小时，直到磨合到能够反驱即可。
14. **反驱力说明**：带电机反驱力很大是正常的哦，毕竟这可是42步进电机齿槽转矩放大了56倍之后的反驱力。

### 四、 外观与结构优化
15. **结构简化**：如果不想要双端固定的话，可以把底下的结构去掉，直接用打印件外壳就行了。
16. **外观处理**：想要外观好看些可以把铝件外壳选择 **阳极氧化黑色**（不过要多花几十块钱），当然也可以直接金属喷漆，不过我没这么试过。
